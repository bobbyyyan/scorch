**Insert a `## What is Scorch?` section between the badges row and the `## Quick Start` heading.**

The section has exactly 3 paragraphs of prose (no bullet lists, no subheadings). Structure:

**Paragraph 1 -- Compiler pipeline (problem-solution hook):**
- Open with the pain point: traditional sparse tensor libraries require hand-tuned kernels for every combination of sparse format and operation -- adding a new format means writing new kernels from scratch
- Position Scorch as the solution: instead of hand-writing kernels, Scorch uses a compiler approach -- you describe tensor formats declaratively, and Scorch generates optimized C++ kernels automatically
- Mention the compilation pipeline parenthetically: expressions are lowered through Compiler Index Notation (CIN) to a Low-Level IR (LLIR), then to C++ source code that is JIT-compiled and cached
- Tone: accessible but technically precise. No marketing fluff.

**Paragraph 2 -- Format-driven sparsity (key abstraction):**
- Explain the d/cs/o/s notation as Scorch's central abstraction: each dimension is described as dense (d), compressed-sparse (cs), coordinate (o), or singleton (s)
- Give concrete examples mapping to familiar formats: CSR is (d, cs) -- dense rows with compressed-sparse columns; COO is (o, o) -- coordinate storage on both dimensions
- Emphasize the payoff: because the compiler generates kernels from format descriptions, supporting a new sparse format does not require writing new kernel code

**Paragraph 3 -- PyTorch compatibility + JIT caching + performance:**
- Scorch integrates directly with PyTorch -- STensors wrap PyTorch tensors and operations like matmul and einsum accept standard torch.Tensor inputs via from_torch
- JIT compilation detail: the first call to an operation compiles a specialized C++ kernel (with OpenMP parallelization); subsequent calls with the same format combination reuse the cached shared library (.so file) from disk
- Performance reference: in benchmarks from the CGO 2026 paper, Scorch achieved 1.05-5.80x speedups over PyTorch Sparse across sparse matrix and graph neural network workloads
