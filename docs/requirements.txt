# Documentation build dependencies for the Scorch docs site.
#
# The API reference is generated from source docstrings via autodoc, so the
# build imports the `scorch` package. It does NOT require the compiled
# `scorch_ops` extension (that is mocked in conf.py) or a C++ toolchain, but it
# does need `torch` (CPU is fine) plus the `scorch` sources on the path
# (conf.py adds ../../src automatically — no install/compile step needed).
#
# In the local `scorch` conda env `torch` is already present, so
# `pip install -r requirements.txt && make html` works out of the box.
#
# `torch` is intentionally NOT pinned here: on PyPI the default wheel is a large
# CUDA build. The local env already provides it, and CI / ReadTheDocs install a
# CPU-only wheel explicitly (see .github/workflows/docs.yml and
# .readthedocs.yaml). If you are in a bare environment, first run:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
